# smithers-vibelang-e2e

A small public VibeLang project for Smithers' issue-tracking proof (apps/mvp/e2e/issue-tracking.spec.ts in
smithersai/smithers, phase (e)): an issue becomes a TODO, an agent's pull request, CI on it, and a merge that closes
the issue. `npm install && npm run build && npm test`. Throwaway issues and pull requests.
